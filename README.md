# Maryam Abdul Rehman — Portfolio

Flutter Developer portfolio built with React + Vite + Tailwind CSS + Framer Motion.

## About

Personal portfolio for **Maryam Abdul Rehman**, a Flutter Developer with experience in cross-platform mobile apps, Dart, .NET (ASP.NET Core), Python (Flask), and full-stack solutions.

## Features

- Modern dark theme with glassmorphism
- Smooth animations (Framer Motion)
- Responsive design
- Theme customizer
- Contact form (Web3Forms)
- Sections: Hero, About, Skills, Experience, Projects, Services, Contact

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Framer Motion
- React Icons
- Lenis smooth scroll

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
